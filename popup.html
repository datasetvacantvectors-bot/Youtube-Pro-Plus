Cinematic Mode — Read Before Enabling

Cinematic Mode works in both Light & Dark mode on YouTube.

Using Dark Mode? You must turn off Ambient Mode from YouTube's player settings and from this extension panel — otherwise Cinematic Mode won't work as expected.

Please make sure you've read the above before turning this on.
